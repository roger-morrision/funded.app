# Devnet-first delivery — October 4, 2026

Six parallel workstreams implemented and reviewed application, persistence, contract, QA, Devnet evidence, and release improvements. The code is ready for review and an isolated Devnet deployment. **Full public Devnet acceptance is blocked; mainnet go-live is not established.**

## Delivered

- Wallet/account/network changes invalidate unsigned reviews and consent. Boost payments journal their signed identity before broadcasting; ambiguous submissions recover by verification without a duplicate transfer.
- Route-aware polling, stale-response protection, saved/shared discovery filters, draft image restoration, verified receipt CSV exports, service status, and local chat hiding/reporting.
- Persisted, hashed, one-use chat authentication with explicit cluster namespaces and an upgrade migration; bounded requests, safe errors/cache headers, rate limits, price-fetch coalescing, and scoped database updates.
- ABI-compatible contract validation for exact token delivery, reward proofs, SOL arithmetic, router identity, and settlement recipients. The obsolete duplicate contract scaffold is removed.
- Node 24 checks, browser/PostgreSQL/contract CI, dependency maintenance, reproducible build manifests, container metadata, and operational recovery documentation.
