# Phased experience release — 4 November 2026

Scope: implement the six phases approved after the public funded.vip review. This release changes presentation, navigation and listing entitlement lookup; transaction signing, finalized receipt checks and the migration snapshot replay remain authoritative.

| Phase | Delivered | Evidence and limits |
| --- | --- | --- |
| 1. Financial and market clarity | Shared dated market observations for search, Explore labels/filtering/sorting, coin cards and reward lists; included launch lookup independent of metadata RPC; gross reward, net wallet delta and receiver costs together; readable burned tokens alongside exact units. | Unit checks cover newer observations, network scope, unknown/zero values and included versus unverified launches. Stored market observations are presentation only; quotes still require fresh transaction checks. |
| 2. Navigation and mobile | Table/Grid selection controls actual visibility; Explore remembers the clicked result and returns focus; market timestamps stay visible; coin identity and readiness precede secondary content on mobile. | Browser coverage at 320, 360, 390, 768, 1280 and 1440 pixels across the affected flows. ## Validation

- 83 focused Node tests: market facts, callouts, receipt/experience safety, listing entitlement, quote retry, claim recovery, issue authorization and asynchronous migration preparation.
- 40 browser cases across search keyboard behavior, payment costs, issue submission safety, public quote recovery, launch summary and the new flows. The first 360px source quote case exceeded the 45-second harness timeout while Vite initialized; the identical assertion passed with a 120-second startup allowance (46.8 seconds total).
- Five listing recovery browser cases passed against the source server. Source-only component fixtures must not be run against a compiled artifact.
- Production Vite build and source-size budgets passed. The existing large SDK/application chunk warning remains; performance timings are measurements, not a claim that the bundle was optimized.

Live verification artifacts are recorded under `tmp/phases-nov4/`. Mocked API tests do not constitute on-chain end-to-end evidence. Existing confirmed launch, claim and callout records can be used for read-only live regression; no mainnet action or real user wallet is required.
