# Top 300

Open **Top 300** in the main navigation, or visit `https://funded.vip/#top300`.

The index ranks up to 300 tokens in funded.vip's verified directory, including supported paid external listings. It is not a list of all Solana tokens. The current deployment uses Devnet test SOL.

## Rankings

| View | Order | Eligible tokens |
| --- | --- | --- |
| Market cap | Current market cap descending | Market cap available |
| Boosted · sponsored | Active paid multiplier descending, then market cap | At least one active verified boost |
| 24h volume | Observed USD volume descending, then market cap | Recent activity snapshot and SOL/USD quote available |
| 24h trades | Observed trade count descending, then market cap | Recent activity snapshot available |

Equal values use the mint address as a stable tie-breaker. Tokens are deduplicated by mint. The first 300 are selected before filters; filtering preserves their original ranks. Results paginate in groups of 25. Search accepts a name, symbol or mint; filters cover stage, launch tier, paid listings, market cap and known launch age.

Boost purchases use the existing checkout, package prices, finalized payment verification, expiry and payment-recovery flow. Active package multipliers add together. A combined multiplier of 500 or more highlights the token name in gold. Boosts affect only the sponsored view. Expired boosts disappear from that view. Launch promotion tiers and the separate 48-hour Home Featured placement remain distinct from active boosts.

## Data and availability

Directory pages contain 50 records each. Top 300 reads beyond Explore's ordinary first 40 records, reuses feed account snapshots and cached market activity, and batches missing RPC account reads in groups of at most 100. Paging stops at the directory end or the protective 10,000-record ceiling. Incomplete coverage is disclosed; it must not be described as the entire Solana market. Concurrent refreshes reuse the existing market loader. Activity scans retain the existing bounded scan budget. Automatic refresh runs only while this route is active and visible, every 60 seconds; manual Refresh retries sooner.

Market caps use confirmed curve or migrated pool data and the current SOL/USD quote. A completed curve is not a substitute for a migrated pool valuation. Missing values appear as **—**, not zero. Activity snapshots older than five minutes are withheld. Partial observed volume/trade counts are prefixed with **≥**. An external token's paid-listing date is not presented as its launch age. Unpriced directory tokens are counted but cannot receive a market-cap rank. Source failures retain last loaded data with a retry warning; unavailable boosts are not presented as verified zero boosts.

The table has semantic column headers, horizontal scrolling on small screens, full symbols, uncropped logos, 44-pixel controls and keyboard focus states. No wallet connection is required to browse rankings.
